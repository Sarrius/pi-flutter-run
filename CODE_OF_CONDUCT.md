# Code of Conduct

This project follows a simple contributor covenant: be respectful, constructive, and focused on improving the project.

## Expected behavior

- Be welcoming to new contributors.
- Critique ideas and code, not people.
- Give actionable feedback with context.
- Assume good intent, but accept corrections quickly.
- Keep issues and pull requests on topic.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Personal attacks or repeated bad-faith arguing.
- Publishing private information without permission.
- Spam or unrelated promotion.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject pull requests; or block users who violate this code of conduct.

If you need to report a concern, contact the maintainers through GitHub or npm maintainer channels.
